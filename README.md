## ✨ Features

- **Dynamic Project Section:** Highlights key development projects with descriptions, tech stacks, and source links.
- **Skill Overview:** Categorized layout displaying proficiency in frontend, backend, and core computer science areas.
- **Interactive UI Components:** Smooth navigation and interactive elements built entirely using functional React components.

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3, Bootstrap & Material-UI \
- **Language:** JavaScript
- **Hosting/Deployment:** Render
